# Customer Churn — Data Quality and Exploratory Analysis

## Project objective
Audit and clean a synthetic customer churn dataset, document quality decisions, and explore initial patterns.

## Files
- `customer_churn_sample.csv` — original supplied data
- `Customer_Churn_EDA.ipynb` — reproducible profiling, validation, cleaning, outlier screening, and EDA
- `cleaned_customer_churn.csv` — cleaned dataset
- `data_quality_report.md` — quality decisions and summary findings
- `data_dictionary.csv` — field definitions

## Run
1. Install Python 3 and Jupyter.
2. Install dependencies: `pip install pandas numpy matplotlib jupyter`
3. Optional for the enhanced chart style: `pip install seaborn`
4. Keep all files in the same folder and open `Customer_Churn_EDA.ipynb`.
5. Run all cells from top to bottom.

## Main caution
The dataset contains only 15 synthetic rows. Findings are exploratory and should not be generalized to a real customer base.
